# Customer Segmentation Project

## Overview

This project focuses on segmenting customers based on their purchasing behaviour using machine learning.

## Objective

The objective is to identify groups of customers with similar purchasing patterns and understand their characteristics and preferences.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- K-Means Clustering
- Google Colab

## Dataset

The dataset contains customer demographic information, purchasing behaviour, campaign responses, and purchasing channel information.

## Methodology

1. Data Loading
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Feature Scaling
6. Elbow Method
7. Silhouette Analysis
8. K-Means Clustering
9. Cluster Profiling
10. Customer Preference Analysis
11. Visualization

## Features Used for Segmentation

- Recency
- Total Purchases
- Total Spending

## Key Analysis

The project analyzes:

- Customer spending behaviour
- Purchase frequency
- Product preferences
- Purchasing channels
- Customer segments

## Conclusion

K-Means clustering was used to identify customer groups with different purchasing behaviours. The resulting segments provide useful insights into customer characteristics and preferences that can support targeted customer analysis.
